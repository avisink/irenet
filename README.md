# ireNet

ireNet is a lightweight platform that connects donors with verified nonprofits and communities in need. The platform enables individuals and organizations to efficiently donate useful items (food, clothing, supplies, etc.) to those who need them most.

## Overview

ireNet addresses the gap in connecting donors with verified nonprofits by providing a streamlined platform where:

- **Donors** can post available items they want to donate
- **Organizations** can browse donations or post requests for specific needs
- **Admins** can monitor matches and mark completed donations
